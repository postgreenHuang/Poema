# Poema

一座会与你谈诗的私人诗库。当前交付为可运行的桌面原型，产品方向见 [完整方案](product-blueprint.md)。

## 已能使用

- **今日偶遇**：从 5000 余篇本地中英文作品随机换诗，中文优先探索非名篇选本，并分散文体与近期读过的作者；点击文句可点亮它。诗笺、共读与“再遇一首”固定在阅读页顶部。
- **寻诗**：按题名、作者、原句、语言、文体和意象直接筛选；配置 AI 后可切换“联网发现 / 本地诗库”。联网模式查询中文维基文库与英文 PoetryDB 的实时结果，再由 AI 在返回的候选中挑选、解释；点击“在 Poema 阅读与赏析”会取得可辨认的正文、打开站内阅读页，随后可进入独立共读页。两种模式都可补充条件或换一批，模型给出的 ID 必须与真实候选匹配。
- **诗路**：从当前诗按意象、心绪、形式或反向情绪继续阅读，显示具体关联理由，并可回到上一首。
- **AI 共读**：采用独立的整页对话界面，并保留正在讨论的作品入口；每首诗单独保留对话，选句后提问会把该句加入上下文。可配置兼容 `/chat/completions` 的服务与模型。没有模型时，其余阅读功能照常可用。
- **查词与读音**：在阅读页顶部打开独立查词窗，也可以选中诗中字词后查询。模型结合当前文句给出中文拼音或英文音标及简短释义；结果不写入共读对话。多音字、古音与异文请再核对权威字典。
- **诗笺**：收藏、私人笔记、最近浏览与最近共读保存在本机，可导出 JSON，也可通过坚果云本地同步文件夹在多台桌面设备之间合并。
- **阅读主题**：在“偏好与 AI”中切换松烟、夜读、旧纸，或分别微调页面、侧栏、卡片、标题、诗句、次要文字、强调色和分隔线。配色即时生效，仅保存在本机。
- **来源**：每篇作品都有来源链接和许可说明。英文数据来自 PoetryDB，按 CC BY 4.0 署名；中文扩充语料来自 chinese-poetry，并附其 [MIT 许可](public/CHINESE-POETRY-LICENSE.txt)。

## 启动

需要 Node.js 22+。桌面版还需要 Rust stable、Windows C++ Build Tools 和 WebView2。

```powershell
npm install
npm run dev
```

浏览器预览地址为 `http://127.0.0.1:1421`。桌面开发模式：

```powershell
npm run tauri dev
```

构建 Windows 单文件便携 EXE（无需 Node.js 或 Rust，不生成安装器）：

```powershell
npm run build:portable
```

输出路径为 `src-tauri/target/release/poema.exe`，可单独复制和启动，不会弹出后台控制台窗口。Windows 仍需系统具备 Microsoft Edge WebView2 Runtime；它通常随新版 Windows 提供，但不能装进这一个 EXE。本版未制作安装器或签名。

## AI 与隐私

在“偏好与 AI”中填写服务地址、模型 ID 和 API Key。桌面版密钥存于系统凭据库；浏览器预览版密钥仅存在当前标签页的会话存储。共读时 Poema 会向所选模型发送当前诗、选中的诗句以及本首诗最近 12 条对话；AI 寻诗时会发送你的需求及最多 32 篇候选的题名、作者或来源摘要（本地模式还含时代、文体、主题标签和首句），独立查词会发送查询词、作品题名与匹配的当前文句，不发送共读对话；上述功能均不发送整个诗笺或所有浏览记录。联网模式会把检索词发送给维基文库或 PoetryDB；桌面版由 Rust 向固定诗源发起请求，浏览器预览版取决于诗源的 CORS 设置。

联网检索卡片本身只是来源线索；点击站内预览后，取得的文本会连同来源链接保存在本机诗笺中，可再次阅读、共读或同步，但仍标明“在线来源、未校勘”。中文维基文库页面只有在能辨认诗文正文时才显示全文；否则明确降为“摘要预览”，AI 也只依据摘要回答。搜索摘要可能包含异文、注释或版权模板，作者、版本与权利须在原站核对。英文 PoetryDB 在卡片中展示前两行，站内阅读使用该接口返回的诗文。诗源不可用时会显示警告；模型输出若不包含真实候选 ID，不会展示虚构作品。

当前对话回复尚未进行模型供应商的真实密钥联调，使用时需要自行配置服务。AI 解释会要求区分文本、事实和解读，但仍应核对涉及生平、背景和版本的陈述。

## 数据边界

原有 422 首样本之外，新增 4848 篇发现语料：唐诗 1500、宋诗 1368、宋词 1200、元散曲 350、《诗经》240、楚辞 30、《古文观止》短篇 100、《幽梦影》短章 60。扩充语料来自 chinese-poetry@2.0.1 的跨分片抽样，按固定哈希、作者上限、篇幅和缺字规则筛选；元曲仅保留可独立阅读的散曲，排除戏剧片段。样本和逐分片 SHA-256 记录在 `src/data/discovery.json` 与 `src/data/discovery-report.json`。生成脚本为 `scripts/build-discovery.mjs`；重建时先将该 npm 包中脚本列出的分片解压到忽略提交的 `.source-corpus/package/dist/`，再运行 `npm run import:discovery`。

开源原始语料远比目前的离线入选库大；本版仍是经过基本格式筛选的发现库，而非全量总库。全量接入宜迁移到 SQLite 索引并建立逐篇校勘、去重和权利审查流程，避免把海量未经核验的文本直接打包进阅读界面。

中文文本的自动简化字转写尚未逐篇校勘，来源链接和权利说明随每篇作品保存。按心绪筛选时，扩充语料只纳入含明确情绪词面的作品；这是粗略线索而非人工鉴赏结论。

本版尚未接入 Wikisource/Wikidata 增量同步、现代诗授权库、译本与朗读录音，也未实现方案中设想的 SQLite 全文索引。检索目前在本地已打包的作品中完成。

本机收藏、笔记、浏览记录与对话保存在 WebView/浏览器的 `localStorage` 中；JSON 导出可作为额外备份。桌面版可在“偏好与 AI → 坚果云 · 多设备诗笺”中点击“选择文件夹”，选取已由坚果云客户端同步到本机的文件夹，再点击“连接 / 立即同步”；也可手填路径。每台电脑都需要安装坚果云、同步同一个云端文件夹，再在 Poema 中选择各自的本机路径；路径可以不同。Poema 会在该文件夹下建立 `Poema/devices/<设备 ID>.json`，每台设备各写一份快照，约每 20 秒读取其他设备的文件并合并，减少同时写同一个文件产生冲突副本的概率。首次连接会先读取已有快照，再写入本机数据。停止同步不会删除云端文件。

同步文件是明文 JSON，包含收藏、笔记、浏览记录、已预览的在线文本和 AI 共读对话，不包含 API Key、模型地址或模型名称。请只选私人同步文件夹，不要把它作为公开分享目录。离线时本机仍可使用；坚果云完成上传、下载后，Poema 需要再次读取文件才会看到另一台设备的更新。云盘冲突、外部编辑、设备时间差或多端离线同时修改同一收藏状态仍可能带来歧义；重要诗笺建议定期导出 JSON 备份。主题配色和 AI 配置始终只保存在本机。

当前同步是本地快照合并，不是完整的云端数据库，也没有坚果云账号登录或端到端加密。若将来扩大语料与同步规模，仍宜迁移到 SQLite 和版本化的来源/权利模型。
